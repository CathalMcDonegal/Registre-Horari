# Registre Horari 2.0

Versió renovada, mobile-first i preparada per PWA.

## Actualització
1. Descarrega/descomprimeix el ZIP.
2. Puja `index.html`, `manifest.json` i `sw.js` al repositori de GitHub.
3. Mantén les icones actuals del repositori si vols conservar-les.
4. GitHub Pages publicarà la nova versió.

## Dades
La versió 2.0 continua utilitzant la clau `registreHorariMossos` de `localStorage` i reconeix l'estructura de dades de la versió anterior.

Abans d'importar o esborrar dades, la 2.0 crea una còpia local de seguretat.

## Inclou
- Dashboard nou
- Registre ràpid de jornada
- Calendari mensual
- Vista setmanal
- Selecció múltiple
- Agenda de judicis
- Estadístiques i previsió
- Exportació JSON i CSV

- Mode fosc segons el sistema
- Disseny mobile-first
